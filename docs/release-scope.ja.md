# 公開範囲と段階的リリース計画

## 結論

このプロジェクトは、現在の学習フォルダ全体をそのまま公開するのではなく、公開用のクリーンなリポジトリに必要なものだけを選びます。

理由は、現在のフォルダに次の種類のファイルが混在しているためです。

- アプリケーションのソースコード
- 自作の分析ノートと問題データ
- 公式過去問PDFと原文に近い抽出データ
- 個人用の中国語ノート、音声ファイル、生成環境
- ローカルの学習履歴と絶対パス

これらは、公開可否、ライセンス、利用目的が異なります。

## 公開候補

### A. すぐに公開準備できるもの

- フロントエンドの汎用コード
- 問題データのスキーマ
- JSONの検証スクリプト
- 自作のUI、進捗表示、ローカル保存の仕組み
- 原文を転載しない分析手順と集計ロジック
- 日本語のREADME、開発手順、貢献ガイド

### B. 内容を確認してから公開するもの

- 民法・宅建業法・法令上の制限の自作解説
- ひっかけ軸、必備リスト、出題画像などの分析資料
- 自作の正誤問題と解説
- 問題データから作った統計

この区分では、第三者の文章をそのまま再現していないこと、説明が現行法令に対応していること、出典と確認日があることを確認します。

### C. 初期公開版には入れないもの

- 公式過去問PDF
- 公式過去問の全文、選択肢、公式解答のまとまった転載
- 出版社や講座の教材から抽出した文章・画像・音声
- 個人用の学習履歴、ブラウザ保存データ、絶対パス
- `中文语音生成器` の仮想環境、生成済み音声、キャッシュ
- 関係のない個人書類やPDF

## 推奨リリース順

### Phase 0: 公開準備

- 日本語READMEとライセンスを作成
- 公開対象と非公開対象を分離
- 秘密情報、個人情報、絶対パスを確認
- データの出典・確認日・更新方法を定義

### Phase 1: 学習アプリの最小公開版

- 日本語UI
- 科目切替
- 正誤判定と即時解説
- ローカル進捗保存
- 数問の自作サンプルデータ

### Phase 2: 学習データの拡張

- 民法の自作問題と分析タグ
- 宅建業法の自作問題と分析タグ
- 法令上の制限の自作問題と分析タグ
- 論点別・ひっかけ軸別の集計

### Phase 3: 再現可能な分析

- 利用者が自分で権利を確認した資料を入力できる変換スクリプト
- 原文をリポジトリに保存しないローカル分析手順
- データ品質チェックと更新履歴

## ライセンス方針

- コードは MIT License を基本とする
- 自作の学習コンテンツは、公開範囲を確認したうえで CC BY 4.0 を基本候補とする
- 第三者資料は、このプロジェクトのライセンスを適用しない
- 公式資料を含める必要がある場合は、先に利用条件または許諾を確認する

## GitHubに公開する前の最終チェック

- [ ] `git grep` で個人名、メールアドレス、APIキー、絶対パスを確認
- [ ] PDF、音声、仮想環境、キャッシュが含まれていない
- [ ] 公式原題の全文転載がない
- [ ] READMEだけでローカル起動できる
- [ ] 日本語UIとドキュメントの表記が統一されている
- [ ] 問題データの正解、解説、出典、確認日が一致している
- [ ] GitHub上で公開するリポジトリ名とライセンスを確認した
