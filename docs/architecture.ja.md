# アーキテクチャ方針

## 基本構成

```text
takken-study-lab/
├── app/                 # ブラウザで動く学習アプリ
├── data/                # 公開可能な問題データとスキーマ
├── analysis/            # 原文を転載しない分析・集計資料
├── scripts/             # データ検証・変換
├── docs/                # 日本語の設計・公開方針
├── README.md
├── NOTICE.md
└── LICENSE
```

## アプリとデータを分離する理由

アプリ本体は、問題データが増えても変更を少なくできるようにします。データ側には、最低限次の情報を持たせます。

- `id`: 問題を一意に識別するID
- `subject`: 科目
- `topic`: 論点
- `statement`: 問題文
- `answer`: 正誤
- `explanation`: 解説
- `decisiveFact`: 判断を分ける決定的事実
- `trapAxis`: ひっかけの軸
- `difficulty`: 難易度
- `source`: 出典または自作表示
- `checkedAt`: 最終確認日

## 日本語化の方針

日本語を標準表示にします。将来、中国語などを追加する場合も、問題データ本体に翻訳文を混在させず、表示ラベルと解説言語を分けて管理します。

画面上の主な用語は次のように統一します。

| 機能 | 表示語 |
| --- | --- |
| 問題演習 | 問題演習 |
| 正誤判定 | 正誤判定 |
| 正解 | 正解 |
| 解説 | 解説 |
| 決定的事実 | 判断を分ける事実 |
| ひっかけ軸 | ひっかけの軸 |
| 進捗 | 学習進捗 |
| 復習 | 復習する |
| 科目切替 | 科目を選ぶ |

## ローカル保存

ログイン機能を持たない初期版では、学習履歴をブラウザの `localStorage` に保存します。公開版では次の情報だけを保存し、個人情報は保存しません。

- 回答回数
- 正解数
- 最終回答日時
- 復習対象フラグ
- 科目・論点別の進捗

ブラウザの保存領域を消去すると履歴も消えるため、将来はエクスポート・インポート機能を追加します。
