# Webアプリ

ここには、ブラウザだけで動く宅建士学習アプリを配置します。

## ローカル起動

```bash
python3 -m http.server 8767
```

その後、<http://localhost:8767> を開いてください。

`index.html` を `file://` で直接開くと、ブラウザのセキュリティ制限によりJSONデータを読み込めない場合があります。

## 現在の公開版

- 画面文言は日本語です
- `data/subjects.json` には公開版デモ用の自作サンプルだけを収録しています
- 民法、宅建業法のほか、今後追加する科目の切替枠を用意しています
