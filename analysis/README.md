# 試験分析

このディレクトリでは、宅建士試験を「何が出たか」だけでなく、「どの知識を、どの条件を変えて、どの形式で問うか」という単位で整理します。

## 分析の3層

### 1. 知識点の分布

- どの論点が何年・何問登場したか
- ほぼ毎年確認すべき論点は何か
- 出題頻度が低くても、落とすと危険な例外・数字・要件は何か

### 2. 出題方式とひっかけ

- 主体、時点、場所、手続、数字、例外のどこを動かしているか
- 原則と例外を入れ替えていないか
- 「善意」と「善意無過失」など、似た要件を区別させているか
- 申込み、契約、説明、交付などの時点をずらしていないか

### 3. 演習への変換

- 1問を短い正誤問題に変換する
- 正解だけでなく、判断を分ける事実を一つ抜き出す
- その事実を一つ変えた場合に答えがどう反転するかを記録する
- 回答直後に、根拠とひっかけ軸を表示する

## 問題ごとの推奨フィールド

```text
subject          科目
topic            論点
format           出題形式
statement        問題文
answer           正誤または選択肢の答え
decisiveFact     判断を分ける事実
trapAxis         ひっかけの軸
flipCondition    事実を一つ変えた場合の結論
law              条文・判例・制度上の根拠
source           出典または自作表示
checkedAt        最終確認日
lawStatus        対象法令の時点・確認状態
```

## 公開時の考え方

原題の全文を公開することと、原題を分析して自作の学習データを作ることは別の作業です。公開版では、原文をそのまま再配布せず、権利を確認した自作問題、集計結果、分析方法を中心に掲載します。
