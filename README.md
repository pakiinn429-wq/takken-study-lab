# Takken Study Lab

宅建士試験の学習を、データと小さなWebアプリで支援するオープンソース・プロジェクトです。

このプロジェクトでは、単に問題を並べるだけではなく、次の流れを一つの学習サイクルとして扱います。

1. 試験問題から論点・出題形式・ひっかけの型を整理する
2. 重要度と出題傾向を確認する
3. 正誤問題を短時間で解く
4. 判定直後に、理由・決定的事実・ひっかけの軸を確認する
5. 科目別の進捗と弱点を記録する

## ステータス

現在は公開準備中（pre-release）です。日語UIの最小デモ、公開用データ形式、分析方法、公開可能な自作コンテンツを段階的に整備しています。

対象科目は次の順で拡張する予定です。

- 民法（権利関係）
- 宅建業法
- 法令上の制限
- 税・その他
- 借地借家法・区分所有法などの関連分野

## プロジェクトの特徴

- 日本語を基本言語とした学習画面とドキュメント
- ブラウザだけで動くシンプルな正誤問題演習
- リロードやブラウザ終了後も残るローカル進捗
- 科目別、論点別、出題形式別の進捗表示
- 「なぜ正しいか／誤りか」だけでなく、問題文のどこが判断を分けるかを表示
- 問題データとアプリ本体を分離し、データを段階的に追加できる構成

## 使い方（予定）

```bash
cd app
python3 -m http.server 8767
```

ブラウザで <http://localhost:8767> を開きます。`index.html` を直接開くのではなく、ローカルHTTPサーバー経由で起動してください。

公開版には、動作確認用の自作サンプル問題だけを収録しています。完全な学習データは、日語化、正確性確認、公開可能性の確認が終わった科目から追加します。

## 公開するもの・公開しないもの

このリポジトリには、権利関係を確認したコードとコンテンツだけを含めます。

### 公開するもの

- 自作のフロントエンドコード
- 問題データのスキーマ、検証スクリプト、サンプルデータ
- 自作の学習解説、論点整理、ひっかけ分析
- 原文をそのまま再配布しない形で整理した統計・分析方法
- 日本語のセットアップ手順と貢献ガイド

### 初期公開版に含めないもの

- 公式過去問PDFそのもの
- 公式問題・選択肢・解答の全文転載
- 出典や再配布条件を確認していない第三者コンテンツ
- 個人用の音声、学習履歴、ローカル絶対パス、仮想環境

詳しい境界は [`docs/release-scope.ja.md`](docs/release-scope.ja.md) を参照してください。

## 注意事項

本プロジェクトは公式試験実施団体とは関係のない個人・コミュニティによる学習支援ツールです。法令や試験制度は変更される可能性があるため、受験時には必ず最新の公式情報と現行法令を確認してください。
